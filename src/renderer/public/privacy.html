개인정보처리방침

Chordash · 시행일 2026년 10월 9일 · English · 서비스 약관

Chordash(웹 버전 chordash.app, 데스크톱 앱, 안드로이드 앱)는 코드 악보를 입력하고 PDF로 만드는 오픈소스 앱입니다. Chordash에는 운영자의 서버가 없습니다. 사용자의 곡과 정보를 운영자가 모으거나 보관하지 않습니다.

1. 곡이 저장되는 곳

  • 이 브라우저 / 휴대폰 / 컴퓨터: 곡과 설정은 사용자의 기기 안에만 저장됩니다.
  • 구글 드라이브 (웹 버전, 사용자가 로그인한 경우): 사용자 본인의 구글 드라이브에 있는 Chordash 폴더에 저장됩니다.

2. 구글 계정 정보의 사용

구글로 로그인하면 Chordash는 drive.file 권한만 요청합니다. 이 권한으로는 Chordash가 직접 만들거나 연 파일만 볼 수 있고, 드라이브의 다른 파일은 볼 수 없습니다. 화면에 로그인 상태를 보여 주기 위해 구글 드라이브가 알려 주는 이름, 이메일 주소, 프로필 사진을 브라우저 안에서만 표시할 수 있습니다.

  • 구글 데이터는 사용자가 요청한 곡 열기·저장에만 쓰고, 다른 곳으로 보내지 않습니다.
  • 구글 데이터를 팔거나, 광고에 쓰거나, AI 학습에 쓰지 않습니다.
  • 로그인 토큰은 브라우저 메모리에만 두고, 탭을 닫으면 사라집니다.

Chordash가 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책과 그 제한적 사용(Limited Use) 요건을 따릅니다.

연결을 끊으려면 구글 계정 → 서드파티 연결에서 Chordash를 삭제하세요. 드라이브의 Chordash 폴더는 사용자가 직접 지울 수 있습니다.

3. AI 악보 읽기 (데스크톱·안드로이드 앱)

사용자가 자기 Anthropic API 키를 넣고 "사진·PDF (AI)" 가져오기를 쓰면, 고른 사진이나 PDF가 Anthropic(Claude)에 직접 보내져 글로 바뀝니다. 이때 Anthropic의 개인정보처리방침이 적용됩니다. API 키는 사용자 기기 안에만 저장됩니다. 웹 버전에는 이 기능이 없습니다.

4. 브라우저 저장소

웹 버전은 곡, 마지막으로 고른 저장 위치, 처음 실행 여부 같은 설정을 브라우저 저장소에 둡니다. 광고나 추적용 쿠키·분석 도구는 쓰지 않습니다. 브라우저의 사이트 데이터를 지우면 함께 지워집니다.

5. 새 버전 확인 (데스크톱·안드로이드 앱)

앱을 켜면 GitHub에 Chordash의 최신 버전이 무엇인지만 물어봅니다. 곡이나 개인 정보는 보내지 않습니다. 새 버전을 받으면 GitHub에서 설치 파일을 내려받습니다(GitHub의 방침이 적용됩니다).

6. 링크로 곡 공유

"링크로 공유"는 곡 글을 압축해 링크의 # 뒤에 담습니다. 브라우저는 이 부분을 서버로 보내지 않으므로, 곡은 링크를 받은 사람의 기기에서만 열립니다. 링크를 가진 사람은 누구나 곡을 볼 수 있으니 보낼 곳을 확인해 주세요.

7. 사이트 호스팅

웹 버전은 GitHub Pages로 제공되고, 도메인은 Cloudflare를 거칩니다. 이 회사들은 사이트를 보여 주기 위해 접속 기록(IP 주소 등)을 남길 수 있으며, 각 회사의 방침이 적용됩니다.

Privacy Policy

Chordash · Effective October 9, 2026

Chordash (the web version at chordash.app, the desktop app and the Android app) is an open-source app for writing chord charts and making PDFs. Chordash has no server of its own; the developer does not collect or keep your songs or personal data.

Where songs are stored

On your own device, or — when you sign in with Google on the web version — in the Chordash folder of your own Google Drive.

Google user data

Chordash requests only the drive.file scope, which lets it see only the files it created or opened, not the rest of your Drive. It may show the name, email address and profile photo that Drive reports, inside your browser only, to show who is signed in. Google data is used only to open and save the songs you ask for; it is never sent elsewhere, sold, used for advertising, or used to train AI models. The access token stays in browser memory and is gone when the tab closes.

Chordash's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. You can remove access at Google Account → Third-party connections.

AI chart reading (desktop and Android apps)

If you enter your own Anthropic API key and import a photo or PDF with AI, that file is sent directly to Anthropic (Claude) and Anthropic's privacy policy applies. The key is stored only on your device. The web version has no AI features.

Update checks (desktop and Android apps)

On start, the apps ask GitHub which Chordash version is the newest. No songs or personal data are sent. Updates are downloaded from GitHub, under GitHub's policies.

Share links

"Share link" puts the compressed song after the # of a link. Browsers do not send that part to any server, so the song opens only on the device of whoever has the link — and anyone with the link can read it.

Browser storage and hosting

The web version keeps songs and settings in browser storage. No advertising or tracking cookies or analytics are used. The site is served by GitHub Pages through Cloudflare, which may keep access logs under their own policies.
