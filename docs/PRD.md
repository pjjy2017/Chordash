# PRD — Chordash

## 1. 목적
손으로 쓰던 간단한 코드 악보(제목, 섹션, 한 줄 여러 마디, 마디당 코드 1~2개, 가사 큐, 간단한 주석)를
**최소한의 타이핑**으로 입력하고, 가독성 좋은 A4 PDF로 내보내는 Windows 데스크톱 앱.
주 사용 목적은 밴드 연주용 차트(커버 편곡 포함)이며, 보컬 키에 맞춘 조옮김이 잦다.

## 2. 핵심 원칙
1. **입력 속도 최우선.** `c#-^7`, key E에서 `3+7` 같은 단축 입력을 즉시 해석한다.
2. **원본 보존.** 파일에는 입력한 텍스트를 그대로 저장하고, 변환 결과는 미리보기와 힌트로만 보여준다.
3. **미리보기 = PDF.** 화면에 보이는 페이지가 그대로 PDF가 된다.

## 3. 화면 구성
- **통합 편집 화면** (CodeMirror 6) — 입력하는 자리가 곧 악보
  - 한 칸(마디)을 쉼표로 닫고 다음 칸으로 넘어가면(또는 다른 줄·다른 곳으로 이동하면) 그 칸의 코드가 그 자리에서 악보 모양으로 바뀜. 띄어쓰기만으로는 바뀌지 않음. 쉼표·마침표는 마디선(| ‖)으로 보임. 칸을 누르면 원래 친 글자로 펼쳐져 고칠 수 있음. 파일에는 친 글자 그대로 저장
  - 고치는 중인 코드 옆 회색 힌트(예: `3+7` 옆에 `G♯aug7`), 해석 불가 토큰은 빨간 밑줄 + 이유
  - 자동 완성: `t`→`title:`, `k`→`key:`, `l`→`lyric:`, `[`→섹션 이름, `{`→메모 색, `key:` 뒤→키 목록
  - 문법 색칠, 줄 번호, 되돌리기
- **머리말 입력 칸:** 에디터 위의 제목 칸과 키 칸(자유 입력: `F`, `c-`, `Bb`, `F#m`, `C단조` 등, 옆에 "C 단조"처럼 읽은 결과 표시). 파일의 `title:` `key:` 줄과 연동
- **인쇄 미리보기(A4):** 넓은 화면은 오른쪽(숨길 수 있음), 좁은 화면은 "입력 / 미리보기" 탭
- **상단 툴바:** 새 파일, 열기, 저장, PDF 내보내기, 힌트, 미리보기 (이후 임포트·조옮김 추가)

## 4. 기능 범위

### v1 (필수)
| 기능 | 요약 |
|---|---|
| 텍스트 문법 | `docs/SYNTAX.md` 전체 |
| 단축 입력 해석 | 기호(`- ^ % o + s`), 소문자 루트, 음계 도수 입력 |
| 레이아웃 | 줄마다 마디 수 자유, 한 줄 안 마디 폭 균등 |
| 페이지 넘김 | 자동(섹션 라벨이 페이지 끝에 혼자 남지 않게, 섹션 전체가 다음 쪽에 들어가면 통째로 넘김) + 수동(`---`) |
| 페이지 제목 | 2쪽부터 "제목 2", "제목 3"… 자동. 1쪽 제목 줄 오른쪽에 "Key F", 섹션에서 키가 바뀌면 섹션 이름 옆에 "Key G" |
| 테마 | "플레인" 하나: 보통 굵기, 한 줄 표기(Cmaj7, C−7♭5), 마이너 `−`. 폰트 앱 내장 |
| 조옮김 | 전체/섹션 단위. 키에 맞는 ♭/♯ 자동 선택. 절대 코드는 미리보기에서만 옮기고, "원본에 적용" 명령으로 텍스트 덮어쓰기 |
| 주석 | 별표, 브레스 마크, 지시문, 색 메모 |
| 파트(송폼) | `a)` `b2)` `ㄱ4)` 를 줄 맨 앞에 써서 파트 표시(네모 상자), 파트만 있는 줄로 송폼 표시 |
| 반복 | `||:` `:||`, 1·2번 엔딩 |
| 파일 | 곡당 UTF-8 텍스트 파일(`.chord`). 열기/저장/다른 이름 저장, 미저장 종료 경고 |
| PDF 출력 | Electron `printToPDF`, 폰트 임베드 |

### v1.x — 임포트 (v1 핵심 완료 후)
| 기능 | 요약 |
|---|---|
| 텍스트 임포트 | 기존 텍스트 악보를 Chordash 문법으로 변환. 오프라인, 규칙 기반 |
| 이미지·PDF 임포트 | 손글씨/인쇄 악보 이미지·PDF를 읽어 Chordash 문법으로 변환. Claude API(비전) 사용 |

공통 흐름: **파일 선택 → 변환 → 새 탭에 결과 텍스트 → 원본과 나란히 보며 검토·수정 → 사용자가 저장.**
자동 저장하지 않으며, 확신이 낮은 부분은 `?` 표시(SYNTAX 참고)를 달아 검토를 유도한다.

#### 텍스트 임포트 상세
지원 입력 형식:
1. **마디선 있는 텍스트** (`| C | Am |`) — 거의 그대로 변환, 코드 표기만 정규화
2. **코드-가사 2줄 형식** (가사 위 줄에 코드가 적힌 웹 악보 형식) — 코드 줄 자동 판별(토큰 대부분이 코드로 해석되면 코드 줄). 가사 줄은 앞부분만 가사 큐로
3. **ChordPro** (`.cho`, `.chopro`, `.crd`) — `{title:}`, `{key:}`, 섹션 지시어(`{start_of_chorus}` 등), 인라인 `[C]` 코드 처리
- 2·3번은 원본에 마디 정보가 없으므로 **가사 한 줄 = 악보 한 줄, 코드 하나 = 한 마디**로 추정하고 줄 끝에 `?` 경고를 단다
- 문자 인코딩 자동 판별: UTF-8, UTF-8 BOM, **CP949(EUC-KR)** — 한국어 텍스트 파일은 CP949가 흔함
- 판별 실패 시(형식 불명) 선택적으로 이미지 임포트와 같은 Claude API 변환을 제안

#### 이미지·PDF 임포트 상세
- 입력: PNG, JPG, PDF(여러 쪽)
- 방식: Claude API 비전 모델에 이미지(또는 PDF)를 보내고, **SYNTAX.md 요약을 포함한 시스템 프롬프트**로 Chordash 문법 텍스트만 출력하게 한다
  - 읽기 불확실한 코드·마디는 `?` 표시로 출력하도록 지시
  - 색이 다른 메모는 `{색: …}`로, 별표·브레스 마크도 해당 기호로
- 검토 화면: 왼쪽 원본 이미지(쪽 넘김), 오른쪽 변환 텍스트+미리보기
- API 키: 설정 화면에서 사용자가 입력, Electron `safeStorage`로 암호화해 사용자 PC에만 저장. 호출은 메인 프로세스에서만
- 보내기 전 확인: 전송할 쪽 수를 보여주고 사용자가 실행 버튼을 누를 때만 전송
- 인터넷 연결 필요. 실패 시 원본 파일과 오류 메시지를 보여주고 아무것도 덮어쓰지 않음
- 사용 모델은 설정에서 바꿀 수 있게(기본값은 구현 시점의 최신 권장 모델로 정하고 DECISIONS에 기록)

### 나중에
- 셋리스트 PDF (여러 `.chord` 파일을 순서대로 묶어 한 PDF로)
- 미리보기에서 직접 편집
- 파트별 출력 (기타용/보컬용)
- 절대 코드 ↔ 도수 표기 일괄 변환

## 5. 비목표 (v1에서 하지 않음)
- 오선보, 리듬 표기, 멜로디 입력
- 오디오 재생
- 클라우드 동기화, 계정
- macOS/모바일

## 6. 기술 스택
| 영역 | 선택 |
|---|---|
| 앱 | Electron + TypeScript + Vite |
| 에디터 | CodeMirror 6 |
| 테스트 | Vitest |
| PDF 출력 | Electron `webContents.printToPDF` |
| PDF 읽기(임포트) | pdf.js (쪽을 이미지로 렌더링하거나 미리보기에 표시) |
| 이미지 인식 | Anthropic Claude API (`@anthropic-ai/sdk`, 메인 프로세스) |
| 폰트 | Geist(영문·숫자·코드 이름), Pretendard(한글·△), Noto Music(♭♯) — 모두 SIL OFL, 앱에 내장 |
