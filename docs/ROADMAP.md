## Phase 13 — 1.1 패치 (모은 고칠 점 한 번에)
사용자 결정: 고칠 점을 모았다가 한 번에 진행. 아래 1~8을 이 단계에서 함께 작업. (구현 완료 — 사용자 확인 대기)
- **완료 기준:** 웹·데스크톱·안드로이드에서 새 화면(A안, 차콜, 메뉴, 휴대폰 아래 탭)으로 곡을 쓰고, `_`/`^` 가사·글자가 악보에 맞게 나오며, 줄을 넘길 때 악보 모양으로 바뀌고, 도움말(F1)에서 모든 입력법을 볼 수 있다.
- [x] 1. **입력법 설명 탭:** 모든 단축 입력·기호·줄 종류·명령을 한곳에서 볼 수 있는 "도움말" 화면(SYNTAX 요약, 예시와 결과를 나란히).
- [x] 2. **"힌트" 옵션 알기 쉽게:** 무엇을 하는지(입력 중인 칸 옆에 해석된 코드 이름을 회색으로 보여 줌) 이름이나 설명으로 드러나게. 1번 설명 탭에도 포함.
- [x] 3. **악보 모양으로 바뀌는 시점을 줄 단위로:** 지금은 쉼표로 칸을 닫으면 바로 바뀜(Phase 4.5 결정). 앞으로는 커서가 있는 줄 전체를 글자 그대로 두고, Enter로 줄을 넘기거나 다른 줄로 옮겨 가면 그 줄이 악보 모양으로 바뀌게. (결정 바뀜 → DECISIONS에 기록)
- [x] 4. **화면 정리 — A안(미니멀 아이콘 툴바):** 흰 바탕·얇은 선, 테마 색은 로고와 PDF 버튼에만. 버튼은 아이콘으로 "파일 / 악보 도구 / 내보내기" 묶음, 덜 쓰는 기능(가져오기·셋리스트·설정·도움말)은 `⋯` 메뉴. 휴대폰은 위에 곡 제목 + `⋮`, 아래에 입력/악보/곡 탭. 제목·키·조옮김·123/CDE 줄을 한 줄로 정리, 모든 창(대화상자) 모양 통일. 데스크톱은 단축키 표시, 웹은 메뉴에 "데스크톱 앱 받기".
- [x] 5. **테마 색 — 차콜 잉크(#23272f):** 남색(#1d3f9e)을 차콜로 바꿈. 앱 화면의 강조색, 로고 아이콘(데스크톱·안드로이드·웹 `npm run icons`), 안드로이드 시작 화면·아이콘 배경 모두. 필요하면 메모 청록을 작은 포인트로.
- [x] 6. **유리 효과는 살짝만:** 위쪽 툴바·휴대폰 아래 탭·메뉴·창(대화상자) 배경만 반투명 흐림. 입력 칸과 악보 미리보기는 불투명 흰 바탕. 흐림을 못 쓰거나 "동작 줄이기"가 켜진 기기는 일반 반투명으로.
- [x] 7. **오픈소스 + 후원:** 라이선스 파일(MIT) 추가, README와 앱 메뉴에 후원 링크(GitHub Sponsors 등 — 사용자가 계정을 만든 뒤 주소 확정). 데스크톱 "정보" 창에 버전·라이선스·글꼴 라이선스(SIL OFL) 표시.
- [x] 8. **가사·위쪽 글자를 `_` / `^`로:** 줄 맨 앞 `_ 가사`(마디 줄 아래), `^ 글자`(마디 줄 위). 쉼표·`|`로 나누면 마디마다. 코드 줄 끝에 이어 써도 됨(`^`는 앞에 띄어쓰기가 있을 때만, `F ^7` 같은 실수는 경고). `l:`·`{색: }`·마디 안 `"Break"`·지시문 줄은 그대로 유지. `>`는 계속 예약.
