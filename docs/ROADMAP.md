# ROADMAP

**현재 단계: Phase 1** (Phase 0 완료 — 사용자 확인 대기)

각 단계는 "완료 기준"을 사용자가 직접 확인하면 끝납니다.

## Phase 0 — 환경과 뼈대
- [x] Electron + Vite + TypeScript 프로젝트 생성 (생성 도구는 최신 권장 방식을 확인해 선택, DECISIONS에 기록)
- [x] Vitest 설정, 샘플 테스트 1개
- [x] 폴더 구조: `src/core`, `src/renderer`, `src/main`
- [x] Git 저장소 초기화, `.gitignore`
- **완료 기준:** `npm run dev`로 빈 창이 뜨고, `npm test`가 통과한다.

## Phase 1 — 파서와 테스트
- [ ] 코드 토큰 파서: SYNTAX 4장 전체 (절대 코드, 도수, 성질 기호, 확장·변형, 베이스)
- [ ] 키·철자 계산: SYNTAX 5장
- [ ] 문서 파서: 머리말, 섹션, 마디 줄, 가사 큐, 지시문, 색 메모, 반복·엔딩, `* ' ?`, `---`
- [ ] SYNTAX 7장 테스트 케이스 전부 자동 테스트화
- [ ] `examples/샴푸의요정.chord` 파싱 오류 0개
- **완료 기준:** `npm test` 전부 통과.

## Phase 2 — 미리보기 렌더링
- [ ] 문서 모델 → A4 페이지 HTML (기본 테마)
- [ ] 마디 균등 폭, 마디당 코드 배치, 가사 큐, 섹션 라벨
- [ ] 자동 페이지 넘김 + `---`, 2쪽부터 "제목 N"
- **완료 기준:** 예제 파일이 원본 손글씨 악보와 같은 구성으로 그려진다.

## Phase 3 — 에디터와 힌트
- [ ] CodeMirror 6 에디터, 문법 색칠
- [ ] 코드 옆 회색 해석 힌트, 오류 빨간 밑줄 + 툴팁
- [ ] 입력 즉시 미리보기 갱신
- [ ] 열기/저장/다른 이름 저장, 미저장 종료 경고
- **완료 기준:** 빈 파일에서 곡 하나를 입력해 저장하고 다시 열 수 있다.

## Phase 4 — PDF 출력과 테마
- [ ] `printToPDF`로 미리보기와 동일한 PDF
- [ ] 폰트 내장, ♭♯△ø° 글리프 확인
- [ ] 테마 2종(굵은 고딕, 플레인) 전환, 확장음 표기 테마별
- **완료 기준:** 예제 PDF를 인쇄해 연주에 쓸 수 있는 수준.

## Phase 5 — 조옮김
- [ ] 전체/섹션 조옮김 (미리보기)
- [ ] "원본에 적용" 명령 (절대 코드 텍스트 덮어쓰기)
- **완료 기준:** SYNTAX 7.5 통과, 예제 곡을 다른 키로 PDF 출력.

## Phase 6 — 반복기호와 주석 렌더링
- [ ] `||: :||`, 1·2번 엔딩 괄호
- [ ] 별표, 브레스 마크, 지시문, 색 메모
- **완료 기준:** 예제 곡의 주석이 모두 표시된다.

## Phase 7 — 텍스트 임포트
- [ ] 인코딩 판별 (UTF-8 / BOM / CP949)
- [ ] 마디선 텍스트, 코드-가사 2줄 형식, ChordPro 변환
- [ ] 추정 부분 `?` 표시, 새 탭에 결과
- [ ] 형식별 샘플 파일과 테스트
- **완료 기준:** 형식별 샘플 3종이 검토 가능한 결과로 변환된다.

## Phase 8 — 이미지·PDF 임포트
- [ ] 설정 화면: API 키 입력, `safeStorage` 저장, 모델 선택
- [ ] PDF 쪽 렌더링(pdf.js), 전송 전 확인 대화상자
- [ ] Claude API 호출(메인 프로세스), SYNTAX 요약 시스템 프롬프트
- [ ] 원본 이미지 ↔ 결과 텍스트 나란히 검토 화면
- **완료 기준:** 원본 손글씨 악보 PDF를 넣어 큰 수정 없이 예제 파일과 비슷한 결과가 나온다.
