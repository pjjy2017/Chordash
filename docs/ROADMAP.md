- **완료 기준:** 예제 PDF를 인쇄해 연주에 쓸 수 있는 수준.

## Phase 4.5 — 입력 편의
- [x] 가사 큐 입력을 `l:` / `lyric:`으로 변경, `>`는 나중 기능을 위해 비워 둠(쓰면 안내 오류)
- [x] 머리말 입력 칸: 제목·키를 에디터 위 칸에서 자유 입력, 파일의 `title:` `key:` 줄과 연동
- [x] 자동 완성: 줄 앞 `t`→`title:`, `k`→`key:`, `l`→`lyric:`, `[`→섹션 이름, `{`→메모 색, `key:` 뒤→키 목록
- [x] 통합 편집 화면: 다 친 코드(쉼표·띄어쓰기·줄바꿈·다른 곳 클릭 시)를 그 자리에서 해석 결과로 보여주고, 누르면 원래 글자로 펼침. 파일에는 원래 글자 저장
- [x] A4 미리보기는 "인쇄 미리보기" 탭/버튼으로 유지
- [x] 파트(송폼) 표시: 줄 맨 앞 `a)` `b2)` `ㄱ4)` → 네모 상자, 파트만 있는 줄은 송폼 줄
- **완료 기준:** 처음 쓰는 사람이 문법 문서를 보지 않고 입력 칸과 자동 완성만으로 곡 하나를 입력할 수 있다.
