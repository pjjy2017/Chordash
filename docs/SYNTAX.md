# SYNTAX — chordpad 입력 문법

이 문서는 파서의 기준입니다. 맨 아래 **테스트 케이스 표**의 모든 행은 자동 테스트로 존재해야 합니다.

## 1. 파일 구조

```
title: 곡 제목
key: F

[Verse]
| Bb^7 | A-7 | Bb^7 | F B7* |
> 가사 큐
```

- 파일 맨 위의 `title:`, `key:` 줄이 머리말입니다. (`key:`가 없으면 도수 입력은 오류)
- 빈 줄은 무시합니다. 레이아웃상 줄 간격을 띄우지 않습니다.
- `//` 로 시작하는 줄은 주석이며 출력되지 않습니다.

## 2. 줄 종류

| 줄 시작 | 의미 | 예 |
|---|---|---|
| `[이름]` | 섹션 라벨. 뒤에 `key: X`를 붙이면 이 섹션부터 키 변경 | `[Chorus 3] key: G` |
| `\|` 또는 `\|\|:` 또는 `1.` `2.` | 마디 줄 | `\| C \| A- \|` |
| `>` | 가사 큐. 바로 위 마디 줄 아래에 표시 | `> 첫 소절` |
| `"…"` | 지시문. 섹션 라벨 뒤에 붙이거나 단독 줄 | `[Intro] "드럼 4마디"` |
| `{색: 내용}` | 색 메모(단독 줄). 바로 아래 마디 줄 위에 표시 | `{teal: 따-닷 따-닷}` |
| `---` | 수동 페이지 넘김 | |

색 이름: `teal`, `red`, `blue`, `green`, `orange`, `purple`, `gray` (테마가 실제 색값을 정함).

## 3. 마디 줄

- `|` 로 마디를 나눕니다. 줄마다 마디 수는 자유이며, 한 줄 안에서는 마디 폭이 균등합니다.
- 한 마디 안의 코드는 공백으로 구분합니다: `| A- D- |`
- 빈 마디 `| |` 는 앞 코드가 계속됨을 뜻하며 비워서 그립니다.
- 반복: `||:` 반복 시작, `:||` 반복 끝
- 엔딩: 줄 맨 앞에 `1.` 또는 `2.` → 그 줄 위에 엔딩 괄호 표시
  ```
  ||: C | A- | F | G7 |
  1.| C | A- | F | G7 :||
  2.| C | A- | F G | C |
  ```

### 코드 앞뒤 표시
| 표시 | 위치 | 의미 | 예 |
|---|---|---|---|
| `*` | 코드 뒤 | 별표(강조) | `B7*` |
| `'` | 코드 앞 | 브레스 마크(V) | `'E-9` |
| `?` | 코드 앞 | 확인 필요(임포트 결과 등). 에디터에서 강조, PDF 출력 시 경고 | `?C#7` |

## 4. 코드 토큰 문법

```
코드   = 루트 성질? 확장? 변형* 베이스?
루트   = 절대루트 | 도수
절대루트 = [A-Ga-g] [#b]?
도수   = [#b]? [1-7]
베이스 = "/" (절대루트 | 도수)
```

### 4.1 루트
- 소문자는 대문자로 변환: `c#7` → C#7
- **`b` 규칙:** 토큰 맨 앞의 소문자 `b` 바로 뒤에 숫자가 오면 **플랫 도수**입니다. 그 외의 소문자 `b`는 루트 B입니다.
  - `b7` → ♭7도, `b-7` → Bm7, `bb^` → B♭maj7, `bb7` → B♭7
  - B7 코드는 대문자 `B7`로 씁니다.
- **도수:** `key:` 기준 음계 도수(1~7). 앞에 `b`/`#`으로 반음 조정.
  - 숫자만 쓰면 **항상 메이저**: key E에서 `2` → F# (마이너는 `2-`)
  - **첫 숫자만 도수**이고 나머지 숫자는 확장음: `57` → B7, `513` → B13
  - 도수 범위(1~7) 밖이면 오류: `8`, `b9`

### 4.2 성질 기호
| 입력 | 의미 | 정규형 |
|---|---|---|
| (없음) | 메이저 | |
| `-` 또는 `m` | 마이너 | m |
| `^` 또는 `maj` | 메이저 7 (`^7`도 같음, `^9`는 maj9) | maj7 |
| `-^` | 마이너 메이저 7 | mM7 |
| `%` 또는 `m7b5` | 하프디미니시 | m7♭5 |
| `o` 또는 `dim` | 디미니시 (`o7`은 dim7) | dim |
| `+` 또는 `aug` | 오그멘티드 (`+7`은 aug7) | aug |
| `s` 또는 `sus4` | sus4 | sus4 |
| `s2` 또는 `sus2` | sus2 | sus2 |

### 4.3 확장·변형
- 확장음 숫자: `6 7 9 11 13`, `add9` 등
- 변형: `b5 #5 b9 #9 #11 b13` — 괄호는 있어도 없어도 됨: `E7(b9)` = `E7b9`

### 4.4 베이스(슬래시)
- 절대음 또는 도수: `A7/C#`, key E에서 `5/7` → B/D#

## 5. 키와 음이름 철자
- 섹션의 `key:`는 다음 `key:` 선언 전까지 유지됩니다.
- **도수 → 음이름은 글자 기준으로 철자를 정합니다.** 도수 n의 글자 = 키 글자에서 n−1번째 글자, 그 다음 반음 수를 맞춥니다.
  - key E: `b7` → D (D#에서 반음 내림), `#4` → A#, `b3` → G
  - key F: `4` → B♭, `#4` → B
- 이중 ♯/♭가 나오면 단순한 이명동음으로 바꿉니다: key C#에서 `#4` → F## → G
- 조옮김도 같은 원리: 목표 키의 글자 기준으로 철자를 정합니다.
- 키 표기 가능 값: `C C# Db D Eb E F F# Gb G Ab A Bb B` 및 마이너 키 `Am` 등(마이너 키의 도수 기준은 같은 이름의 자연단음계)

## 6. 표시(렌더링) 규칙
- 해석된 코드는 정규형으로 저장하고, **표시는 테마가 결정**합니다.

| 정규형 | 굵은 고딕(기본) | 플레인 |
|---|---|---|
| maj7 | △7 (위첨자) | maj7 |
| m7♭5 | ø7 (위첨자) | m7♭5 |
| dim7 | °7 | dim7 |
| aug7 | +7 | aug7 |
| 7♭9 | 7♭9 (위첨자) | 7♭9 |

- 확장음 위첨자 여부는 테마 설정값 (`extensionStyle: "superscript" | "inline"`).

## 7. 테스트 케이스

### 7.1 절대 코드
| 입력 | 결과 |
|---|---|
| `c` | C |
| `c#-^7` | C#mM7 |
| `f#-7` | F#m7 |
| `bb^` | B♭maj7 |
| `Bb^7` | B♭maj7 |
| `B7` | B7 |
| `b-7` | Bm7 |
| `bb7` | B♭7 |
| `d#%` | D#m7♭5 |
| `Em7b5` | Em7♭5 |
| `go7` | Gdim7 |
| `c+` | Caug |
| `c+7` | Caug7 |
| `bs` | Bsus4 |
| `Csus4` | Csus4 |
| `cs2` | Csus2 |
| `e7b9` | E7♭9 |
| `E7(b9)` | E7♭9 |
| `e7#9` | E7♯9 |

### 7.2 도수 (key: E)
| 입력 | 결과 |
|---|---|
| `1` | E |
| `2` | F# |
| `2-` | F#m |
| `2-7` | F#m7 |
| `4^7` | Amaj7 |
| `57` | B7 |
| `513` | B13 |
| `3+7` | G#aug7 |
| `7` | D# |
| `b7` | D |
| `b77` | D7 |
| `b3-7` | Gm7 |
| `#4%` | A#m7♭5 |
| `5/7` | B/D# |

### 7.3 도수 (key: F)
| 입력 | 결과 |
|---|---|
| `4` | B♭ |
| `#4o7` | Bdim7 |
| `b7` | E♭ |
| `2-7` | Gm7 |

### 7.4 오류
| 입력 | 결과 |
|---|---|
| `8` | 오류: 도수는 1~7 |
| `b9` | 오류: 도수는 1~7 |
| `h7` | 오류: 알 수 없는 루트 |
| `3` (key 없음) | 오류: key가 지정되지 않음 |

### 7.5 조옮김
| 원본 | 조작 | 결과 |
|---|---|---|
| key C, `C7` | → key E | E7 |
| key C, `F^7` | → key Eb | A♭maj7 |
| key E, `3+7` | key를 G로 변경 | Baug7 |
| key G, `F#%` | → key F | Em7♭5 |
