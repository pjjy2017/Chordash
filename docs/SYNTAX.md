# SYNTAX — Chordash 입력 문법

이 문서는 파서의 기준입니다. 맨 아래 **테스트 케이스 표**의 모든 행은 자동 테스트로 존재해야 합니다.

## 1. 파일 구조

```
title: 곡 제목
key: F

[Verse]
Bb^7, A-7, Bb^7, F B7*
l: 가사 큐
```

- 파일 맨 위의 `title:`, `key:` 줄이 머리말입니다. (`key:`가 없으면 도수 입력은 오류)
- 예전 파일의 `theme:` 줄은 무시하고 경고만 냅니다(테마는 플레인 하나).
- 빈 줄은 무시합니다. 레이아웃상 줄 간격을 띄우지 않습니다.
- `//` 로 시작하는 줄은 주석이며 출력되지 않습니다.

## 2. 줄 종류

| 줄 시작 | 의미 | 예 |
|---|---|---|
| `[이름]` | 섹션 라벨. 뒤에 `key: X`를 붙이면 이 섹션부터 키 변경 | `[Chorus 3] key: G` |
| 그 밖의 모든 줄 | 마디 줄 | `C, A-, F, G7.` 또는 `\| C \| A- \|` |
| `l:` 또는 `lyric:` | 가사 큐. 바로 위 마디 줄 아래에 표시 | `l: 첫 소절` |
| `>` | (예약됨 — 나중 기능용. 지금 쓰면 오류) | |
| `"…"` | 지시문. 섹션 라벨 뒤에 붙이거나 단독 줄 | `[Intro] "드럼 4마디"` |
| `{색: 내용}` | 색 메모(단독 줄). 바로 아래 마디 줄 위에 표시 | `{teal: 따-닷 따-닷}` |
| `---` | 수동 페이지 넘김 | |
| 파트 표시만 있는 줄 | 송폼 한눈에 보기. 파트 상자를 한 줄로 그림 | `a) a) b) a)` |

색 이름: `teal`, `red`, `blue`, `green`, `orange`, `purple`, `gray` (테마가 실제 색값을 정함).

## 3. 마디 줄

- 마디선: `,` 또는 `|` = 일반 마디선, `.` = 마침줄. 섞어 써도 됩니다.
- **문장처럼 씁니다:** 줄 맨 앞의 마디선은 생략, 줄 끝의 `,`도 생략할 수 있습니다. 줄의 왼쪽·오른쪽 끝에는 항상 마디선을 그립니다.
  ```
  Bb^7, A-7, Bb^7, F B7*
  E-9, 'E-9.
  ```
  는 `| Bb^7 | A-7 | Bb^7 | F B7* |`, `| E-9 | 'E-9 ‖`(마침줄)와 같습니다.
- 줄마다 마디 수는 자유이며, 한 줄 안에서는 마디 폭이 균등합니다.
- 한 마디 안의 코드는 공백으로 구분합니다: `A- D-`
- 빈 마디 `C, , D` (또는 `| |`)는 앞 코드가 계속됨을 뜻하며 비워서 그립니다.
- 괄호 안의 쉼표는 마디선이 아닙니다: `C7(b9,#11)`
- 반복: `||:` 반복 시작, `:||` 반복 끝
- 엔딩: 줄 맨 앞에 `1.` 또는 `2.` → 그 줄 위에 엔딩 괄호 표시
  ```
  ||: C, A-, F, G7
  1. C, A-, F, G7 :||
  2. C, A-, F G, C.
  ```
  - 줄 맨 앞 `숫자.` 뒤에 내용이 이어질 때만 엔딩입니다. `1.`만 있는 줄은 "1도 한 마디 + 마침줄"입니다.

### 파트(송폼) 표시
- 마디 줄 **맨 앞**에 `글자)` 를 쓰면 그 줄이 그 파트의 시작입니다: `a) Bb^7, A-7, F B7`
- 글자는 영문 한 글자 또는 한글 한 글자, 뒤에 숫자를 붙일 수 있음: `a)` `b)` `b2)` `ㄱ)` `ㄱ4)` `ㄴ)`
- 악보에는 줄 왼쪽 여백에 **네모 상자**로 표시. 영문은 대문자로(`a)` → A, `b2)` → B2), 한글은 그대로
- 파트 표시만 있는 줄(`a) a) b) a) c)`)은 송폼 줄로, 상자들을 한 줄에 그림
- 줄 중간에 쓰면 오류("파트 표시는 줄 맨 앞에만")
- `(` 없이 `)`로 끝나는 코드는 없으므로 코드와 겹치지 않음(`c(b9)`는 코드)

### 코드 앞뒤 표시
| 표시 | 위치 | 의미 | 예 |
|---|---|---|---|
| `*` | 코드 뒤 | 별표(강조) | `B7*` |
| `'` | 코드 앞 | 브레스 마크(V) | `'E-9` |
| `?` | 코드 앞 | 확인 필요(임포트 결과 등). 에디터에서 강조, PDF 출력 시 경고 | `?C#7` |
| `?` | 마디 줄 끝(마지막 마디선 뒤, 또는 공백 뒤) | 이 줄 전체 확인 필요 | `C, A- ?` |

## 4. 코드 토큰 문법

```
코드   = 루트 성질? 확장? sus? 추가? 변형* 베이스?
루트   = 절대루트 | 도수
절대루트 = [A-Ga-g] [#b]?
도수   = [#b]? [1-7]
베이스 = "/" (절대루트 | 도수)
```

### 4.1 루트
- 소문자는 대문자로 변환: `c#7` → C♯7
- 절대루트 뒤의 `b`/`#`는 항상 루트의 임시표입니다: `cb9` → C♭9, `c#9` → C♯9 (C(♭9)는 `c(b9)`로, C7♭9는 `c7b9`로 씀)
- **`b` 규칙:** 토큰 맨 앞의 소문자 `b` 바로 뒤에 숫자가 오면 **플랫 도수**입니다. 그 외의 소문자 `b`는 루트 B입니다.
  - `b7` → ♭7도, `b-7` → Bm7, `bb^` → B♭maj7, `bb7` → B♭7
  - B7 코드는 대문자 `B7`로 씁니다.
- **도수:** `key:` 기준 음계 도수(1~7). 앞에 `b`/`#`으로 반음 조정.
  - 숫자만 쓰면 **항상 메이저**: key E에서 `2` → F♯ (마이너는 `2-`)
  - **첫 숫자만 도수**이고 나머지 숫자는 확장음: `57` → B7, `513` → B13
  - 도수 범위(1~7) 밖이면 오류: `8`, `b9`

### 4.2 성질 기호
| 입력 | 의미 | 정규형 |
|---|---|---|
| (없음) | 메이저 | |
| `-` 또는 `m` | 마이너 | m |
| `^` 또는 `maj` 또는 `M` | 메이저 7 (`^7`·`M7`도 같음, `^9`는 maj9) | maj7 |
| `-^` 또는 `mM` | 마이너 메이저 7 | mM7 |
| `%` 또는 `ø` 또는 `m7b5` | 하프디미니시 | m7♭5 |
| `o` 또는 `dim` | 디미니시 (`o7`은 dim7) | dim |
| `+` 또는 `aug` | 오그멘티드 (`+7`은 aug7) | aug |
| `s` 또는 `s4` 또는 `sus4` 또는 `sus` | sus4 | sus4 |
| `s2` 또는 `sus2` | sus2 | sus2 |

### 4.3 확장·변형
- 확장음 숫자: `6 7 9 11 13`, `69`(6/9 코드), `add9` 등
  - 6/9 코드는 `69`로 입력합니다 (`6/9`는 슬래시 베이스와 겹침): `C69` → C6/9
- sus는 확장음 앞뒤 어디든 됩니다: `cs7` = `c7s` = `C7sus4` → C7sus4
- 알터드: 확장음 뒤 `alt` (도미넌트만). 숫자 없이 쓰면 7로 봄: `B7alt` → B7alt, `Calt` → C7alt
- 변형: `b5 #5 b9 #9 #11 b13` — 괄호는 있어도 없어도 됨: `E7(b9)` = `E7b9`

### 4.4 베이스(슬래시)
- 절대음 또는 도수: `A7/C#`, key E에서 `5/7` → B/D♯

## 5. 키와 음이름 철자
- 섹션의 `key:`는 다음 `key:` 선언 전까지 유지됩니다.
- **도수 → 음이름은 글자 기준으로 철자를 정합니다.** 도수 n의 글자 = 키 글자에서 n−1번째 글자, 그 다음 반음 수를 맞춥니다.
  - key E: `b7` → D (D♯에서 반음 내림), `#4` → A♯, `b3` → G
  - key F: `4` → B♭, `#4` → B
- 이중 ♯/♭가 나오면 단순한 이명동음으로 바꿉니다: key C#에서 `#4` → F𝄪 → G
- 조옮김도 같은 원리: 목표 키의 글자 기준으로 철자를 정합니다. 음은 "글자 몇 칸 + 반음 몇 개"만큼 옮깁니다(key G의 F♯ → key F에서 E).
  - 곡 전체를 옮기면 `key:`와 섹션의 `key:`도 같은 간격만큼 옮겨집니다.
  - **원본에 적용**하면 코드는 친 모양을 유지하고 근음·베이스 글자만 바꿉니다(`Bb^7` → `C^7`, 근음은 항상 대문자). 도수 코드는 그대로 두고 `key:` 줄이 바뀝니다. 일부 줄만 옮길 때는 키가 그대로이므로 그 줄의 도수 코드를 음이름으로 바꿔 씁니다.
- **키는 너그럽게 읽습니다.** 근음 글자(대소문자 무관) + 임시표(`#` `b` `♯` `♭`) + 장단조 표시:
  - 단조: `m`, `-`, `min`, `minor`, `단조` → `c-`, `Cm`, `C minor`, `c단조`는 모두 C단조
  - 장조: 표시 없음, `M`, `maj`, `major`, `장조` → `bb`, `Bb major`, `C장조`
  - 어떤 글자 + 임시표든 됩니다(`Cb`, `E#`). 읽을 수 없는 값만 오류입니다.
  - 마이너 키의 도수 기준은 같은 이름의 자연단음계

## 6. 표시(렌더링) 규칙
- 해석된 코드는 정규형으로 저장하고, 표시는 테마 "플레인"(유일한 테마)이 정합니다: 보통 굵기, 한 줄 표기, 마이너는 `−`.
- 앞에 숫자가 없는 변형은 괄호로 묶어 표시합니다: `c(b9)` → C(♭9) (C♭9와 구분)
- 정규형의 임시표는 루트·베이스·변형 모두 악보 기호 ♯ ♭를 씁니다 (입력은 키보드 `#` `b`).

| 정규형 | 플레인 표시 |
|---|---|
| m7 | −7 |
| maj7 | maj7 |
| mM7 | −maj7 |
| m7♭5 | −7♭5 |
| dim7 | dim7 |
| aug7 | aug7 |
| 7♭9 | 7♭9 |
